# pi-quote-picker

A Pi extension for inserting text from the latest assistant response into the editor.

## Install

```sh
pi install npm:pi-quote-picker
```

## Use

Requires Pi's interactive TUI.

1. Type `>` at the end of an editor line to open the picker.
2. Continue typing to filter paragraphs from the latest assistant response.
3. Use Up or Down to select a paragraph.
4. Press Enter to insert it as a quote, or Alt+Enter to insert plain text.
5. Press Esc to close the picker.
